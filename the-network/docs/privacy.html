Privacy Policy

Last updated: October 2026

About This Policy

This privacy policy explains how we collect, use, and protect information when you use The Network — an internal production management desktop application for authorised production staff.

The Network is a private, internal tool. It is not a public consumer product. Access is restricted to authorised production personnel only.

Data We Collect

When you connect a third-party platform account (such as YouTube) to The Network, we collect and store:

  • Your OAuth access token and refresh token for the connected account
  • Your account name or channel name as returned by the platform's API
  • Analytics data such as view counts, watch time, subscriber counts, and engagement metrics from your connected channels
  • For RSS and podcast feeds: the feed URL you provide

We do not collect passwords. Authentication is handled entirely through the platform's own OAuth flow (e.g. Google Sign-In for YouTube).

How We Use Your Data

All data collected is used exclusively to operate The Network's internal features:

  • Displaying unified platform analytics within the application dashboard
  • Enabling production scheduling and content management workflows
  • Allowing authorised staff to view and manage connected channel information

We do not use your data for advertising, marketing, profiling, or any purpose outside of operating The Network as an internal production tool.

Google API Data

The Network uses Google APIs (including the YouTube Data API v3, YouTube Analytics API, and YouTube Reporting API) to retrieve channel analytics and content information for connected YouTube accounts.

Our use of data obtained through Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is only used to provide and improve the production management features within The Network
  • Google user data is never transferred to third parties except as necessary to provide or improve these features
  • Google user data is never used for serving advertisements
  • Google user data is never used for any purpose unrelated to The Network's core functionality
  • Google user data is never sold or used for any human review unrelated to security and fraud prevention

Data Storage and Security

OAuth tokens and account credentials are stored locally on the user's device in the application's secure data directory using the operating system's application data storage. Data is not transmitted to any external servers, except where directly required to call the respective platform's own API.

Analytics data retrieved from platform APIs is displayed within the application and may be cached locally to reduce API calls. This cached data is stored on the user's device and is not uploaded or shared externally.

Access to The Network requires authenticated login. Access is restricted to authorised production personnel only.

Data Sharing

We do not sell, rent, or share your personal data or platform account data with any third party, except:

  • Where required by law or lawful regulatory authority
  • When making API calls directly to the connected platform (e.g. YouTube) on your behalf — this is inherent to how OAuth authentication works

Data Retention and Deletion

Platform account connections and their associated tokens can be disconnected at any time from within The Network's Connections screen. Disconnecting an account removes its stored access token, refresh token, and associated account data from your device.

You can also revoke The Network's access to your Google account at any time by visiting myaccount.google.com/permissions and removing The Network from the list of connected apps.

Your Rights (UK GDPR)

We comply with the UK General Data Protection Regulation (UK GDPR) and the Data Protection Act 2018. Where applicable, you have the right to:

  • Access the personal data we hold about you
  • Correct inaccurate personal data
  • Request deletion of your personal data
  • Object to or restrict processing of your personal data
  • Data portability

To exercise any of these rights, please contact us using the details below.

Cookies

The Network is a desktop application. It does not use browser cookies. Session state is managed locally within the application using secure storage on your device.

Changes to This Policy

We may update this privacy policy from time to time. When we do, we will update the "last updated" date at the top of this page. Continued use of The Network following any changes constitutes acceptance of the updated policy.

Contact Us

If you have any questions about this privacy policy or how we handle your data, please contact us via the details provided within The Network application.
